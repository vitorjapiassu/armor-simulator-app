# Armor Simulation — aplicativo

Este repositório serve **apenas a versão compilada** do Armor Simulation, para que ele possa ser
aberto e instalado a partir de um endereço próprio: https://vitorjapiassu.github.io/armor-simulator-app/

No Android, abra no Chrome em modo paisagem e use "Instalar aplicativo" no menu. Depois de instalado
ele abre em tela cheia e funciona sem rede.

O projeto — código, benches, testes — vive em outro lugar; aqui está só o que o navegador precisa
baixar.
